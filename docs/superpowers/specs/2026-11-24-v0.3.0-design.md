# v0.3.0 Design: Multi-Symbol Batch Slicing & Token-Savings Telemetry

## Intent
Add batch symbol slicing (`slice_symbols`) and token-savings telemetry (`--stats` flag) to help users understand compression efficiency.

## Goals
1. **SliceStats struct**: Track files_scanned, files_matched, full_files_bytes, sliced_bytes, estimated_tokens_saved, reduction_percent
2. **slice_symbols tool**: Accept `Vec<String>` symbols, deduplicate, merge overlapping spans, enforce max_chars fairly
3. **MCP exposure**: Add `slice_symbols` to tool router in mcp.rs
4. **Agent exposure**: Add `slice_symbols` to CLI ReAct tool loop in agent.rs
5. **CLI updates**: 
   - `treecut slice <SYMBOLS>...` accepts multiple symbols
   - `--stats` flag on map, slice, diff-slice prints telemetry to stderr
6. **Tests**: Overlapping span deduplication, accurate reduction_percent math

## Non-Goals
- Cross-symbol caller analysis beyond span merging
- Persistent telemetry storage

## Constraints
- Zero stdout pollution (stats to stderr only)
- Backward compatible with existing single-symbol slice
- No new dependencies

## Approach

### 1. SliceStats in models.rs
```rust
#[derive(Debug, Clone, Serialize, Deserialize, JsonSchema, Default)]
pub struct SliceStats {
    pub files_scanned: usize,
    pub files_matched: usize,
    pub full_files_bytes: usize,
    pub sliced_bytes: usize,
    pub estimated_tokens_saved: usize,
    pub reduction_percent: f32,
}
```
Add optional `stats: Option<SliceStats>` to `ToolOutput`.

### 2. slice_symbols in slicer.rs
- Build per-file local name map for ALL symbols (original + aliases)
- Single tree-sitter walk per file collecting all matches
- Merge overlapping line ranges within same file
- Fair max_chars allocation: total_max / num_symbols per symbol, or proportional to match count
- Track stats during walk

### 3. MCP tool router (mcp.rs)
Add `slice_symbols` tool with `symbols: Vec<String>` input schema.

### 4. Agent tool loop (agent.rs)
Add `slice_symbols` function to tools array and execute_tool handler.

### 5. CLI (main.rs)
- Change `Slice { symbol: String }` to `Slice { symbols: Vec<String> }` with `required = true`
- Add `--stats` flag to Map, Slice, DiffSlice
- Print stats to stderr when flag present

### 6. Tests
- Multi-symbol fixture with overlapping callers
- Verify reduction_percent = (1 - sliced/full) * 100
- Verify no duplicate output for shared callers

## Estimated Token Calculation
~4 chars per token for code. `estimated_tokens_saved = (full_files_bytes - sliced_bytes) / 4`
